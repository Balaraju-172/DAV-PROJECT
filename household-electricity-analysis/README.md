# ⚡ Household Electricity Consumption & Waste Pattern Analyzer

A **Data Analysis and Visualization (DAV)** project that turns raw household
electricity readings into understandable visual insights — identifying
high-consumption periods, peak hours, weekday/weekend patterns and possible
electricity-waste patterns.

> **Note:** The project flags *potential high-consumption periods* — unusual
> consumption worth investigating — rather than claiming any record is
> definitely wastage. High consumption is not necessarily waste.

---

## Problem Statement

Households receive an electricity bill every month but rarely understand
*when* and *where* their electricity is actually used. Without visibility
into hourly, daily and seasonal patterns, unusual consumption goes unnoticed
until the bill arrives.

This project analyses household electricity readings to answer:

- When does the household consume the most electricity?
- What are the peak consumption hours?
- How does usage differ between weekdays and weekends?
- How does consumption change throughout the day / month by month?
- Is higher voltage associated with higher power consumption?
- Which periods and days have unusually high consumption?
- What share of total consumption occurs during peak hours?
- Which usage category (kitchen / living room / bedroom / other) contributes most?

---

## Objectives

1. Generate a realistic sample dataset of household electricity readings.
2. Clean and validate the data using Pandas.
3. Compute descriptive statistics (total, average, median, std, peak hour…).
4. Perform hourly, daily, monthly and weekday/weekend analysis.
5. Analyse the relationship between voltage and power consumption.
6. Break down estimated consumption by usage category.
7. Detect unusually high-consumption periods using statistical thresholds.
8. Present all findings in an interactive **Streamlit** dashboard.
9. Derive dynamic "Key Insights" from the data.

## Data Cleaning

Performed in `analysis.py → clean_data()` and demonstrated in the notebook:

1. **Shape & types** — `df.shape`, `df.info()` to understand the dataset.
2. **Missing values** — `df.isnull().sum()`; numeric columns are filled with
   the **column median** (robust to outliers) instead of deleting rows.
3. **Duplicates** — `df.duplicated().sum()`; exact duplicate rows and
   duplicated `Record_ID`s are dropped.
4. **Date conversion** — `Date` parsed to Pandas datetime.
5. **Range validation**:
   - power/energy must be ≥ 0 (no negative consumption),
   - `Hour` must be 0–23,
   - voltage must be within a plausible 200–250 V band.

## Analysis

All functions live in `analysis.py` and are shared by the dashboard and the notebook.

### Hourly analysis
Average power per hour; hours are ranked and classified as **Peak / Normal / Low**
using data-driven quartile thresholds (≥ 75th percentile = Peak, ≤ 25th = Low).

### Daily analysis
Total/average/maximum consumption per day; unusually high days flagged with
**Mean + 2 × Standard Deviation** or **IQR (Q3 + 1.5 × IQR)**.

### Monthly analysis
Total/average consumption per month; highest and lowest months identified.

### Weekday vs weekend
Average, total, peak and hourly-profile comparison between weekdays and weekends.

### Voltage analysis
Scatter plot of voltage vs power with the Pearson correlation. The dashboard
explicitly notes that **correlation does not imply causation**.

### Room analysis
Estimated consumption split across Kitchen / Living Room / Bedroom / Other,
labelled clearly as *estimated usage categories* from a simulated dataset.

### Unusual consumption detection
Records above the statistical threshold (IQR or mean + 2σ, selectable in the
sidebar) are marked **Potential High-Consumption Periods** — unusual patterns
worth investigating, not confirmed wastage.

## Dashboard Overview

**⚡ Household Energy Analytics** provides:

- **KPI cards**: total energy, average consumption, peak hour, count of
  potential high-consumption records — all recomputed from the filtered data.
- **Sidebar filters**: date range, day type, month, hour range, detection
  method, plus a reset button. Every chart and KPI updates with the filters.
- **Tabbed sections**: Hourly, Daily, Weekday vs Weekend, Voltage, Rooms,
  Day × Hour Heatmap, High Consumption, Data Explorer.
- **Key Insights**: dynamically computed summary sentences at the bottom.

## Conclusion

This project demonstrates the complete Data Analysis & Visualization pipeline:

```text
DATA → DATA CLEANING → EXPLORATORY ANALYSIS → STATISTICAL ANALYSIS
     → VISUALIZATION → INTERACTIVE DASHBOARD → INSIGHTS
```

Starting from raw electricity readings, we cleaned and validated the data,
uncovered the household's consumption rhythm (evening peak, night trough,
weekend shifts, seasonal variation), quantified the association between
voltage and power, and statistically flagged unusual consumption periods —
all presented through an interactive Streamlit dashboard that lets a user
explore the data with live filters. The same analysis logic (`analysis.py`)
powers both the notebook and the dashboard, showing how reproducible
analysis functions turn a dataset into decisions.
